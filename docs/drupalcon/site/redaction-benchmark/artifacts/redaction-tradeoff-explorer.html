How to read it

Every axis points the same way: up is better

Cost, time and leaks are inverted so that a good result is always high. A line that stays near the top across all four axes is an option with no bad news anywhere. The shaded red band at the foot of each axis is the region your threshold has ruled out — any line entering it is greyed for the rest of the chart.

The control is on the chart, and it fails

B1 is the deterministic pipeline: fetch, convert, done. It is free, it finishes in about a second, and it scores 100% on fidelity by definition — it is the ruler. On three of four axes it is unbeatable. On the medium page it leaks 38 competitor mentions, because it never redacts anything. Pull the leak threshold down to zero and the cheapest, fastest, most faithful option on the board disappears first. That is the whole argument for spending money on a model.

Correction, 5 September: B5 did receive its system prompt

This page previously said B5's instructions never reached the model, via the FlowDrop port bug (flowdrop#3592438) that did hit three early B7 draws. B5 was not affected: its parent workflow forwards the prompt through the sub-workflow's system_prompt input port, and the first-call token counts are identical before and after the port fix. B5's fidelity is a fair reading of the design.

B7 is the same architecture with one change: its converter takes a URL rather than a document, so page content never has to pass back out through the model to reach the tool.

B8 and B9, added 5 September

B8 is B5's prompt with B7's tool: the parent agent is handed a URL-to-Markdown converter. It lands where B7 does on every axis — two calls, the same cost, the same time. B9 wraps that agent in a critic that can send the answer back up to three revisions. On the medium page the critic accepted the first draft, so B9 is B8 plus one call. On the large page three revisions cut leaks from two to one at three times the cost and fourteen minutes of wall clock — pull the time threshold below that and it is the first agent to go. On the small page three revisions cost nine calls and five times B8's money and ended on the same 69% document B8 produced: the critic changed nothing.

The B9 small-page run is a rerun. The first attempt failed inside FlowDrop's loop runtime on the revision round, not in the model (flowdrop#3592443); FlowDrop fixed it the same day and the cell was rerun on the fixed module.

On the small page, the free option is genuinely correct

Switch to the small page with the correctness preset and B1 survives as the cheapest qualifying option. That is not a flaw in the filter — that page contains nothing to redact, so a pipeline that redacts nothing gets the right answer for free. The mirror-image failure, redacting on a page with nothing to redact, is invisible here: a threshold chart can only rule things out on the axes it has, and over-redaction needs its own measure, which this benchmark does not yet have.

Fidelity is de-noised, and it is still only a proxy

Prose kept compares against the control with link targets, image alt blocks and repeated whitespace stripped from both sides — raw character count would credit a model for echoing back URLs. A character metric cannot tell a dropped paragraph from a missed redaction, which is exactly why leaks are a separate axis rather than folded into a single score. B2 on the small page returned raw HTML instead of Markdown and is scored 0%; its cost and time are real.
